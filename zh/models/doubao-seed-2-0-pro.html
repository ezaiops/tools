Doubao Seed 2.0 Pro 的费用

不超过 128K 的 prompt 每 1M 输入 tokens $0.50、每 1M 输出 tokens $3.00,更长的则按 $1.00/$6.00——而且更高档位作用于请求中的每个 token,不只是超出部分。这与 OpenAI、Google、xAI 使用的断崖结构相同,它对长 prompt 的惩罚远超头条费率给人的印象。

这里的断崖格外陡,因为倍率在两侧都是干净的 2 倍。一个 130K-token 的请求,成本是同样请求在 128K 时的 2.02 倍,因此把文档切成两半各 65K 发送,严格比整份发送便宜。

缓存命中按 $0.10 计费,并附带 $0.0083/1M-小时的存储费。Flex 处理把输入输出减半并保持缓存费率;Batch 推理单独定价——在二选一之前,两者都值得与标准费率核算比较。

Pro、Turbo 还是 Lite

Pro 与 Turbo 共享 $0.50 的输入价,所以差异在输出($3.00 对 $2.50)以及 Turbo 没有的档位分界。128K 以下的 prompt,Pro 每个输出 token 贵 20%;128K 以上,Turbo 半价,而且这个对比已不再接近。

Lite 的 $0.25/$2.00 是中间档位,也是抽取与分类工作优先看的一档:128K 以下输入价是 Pro 的一半,窗口同样是 256K。Mini 的 $0.10/$0.40 在输出上压过本表所有其他模型。

常见问题

Doubao Seed 2.0 Pro 每 1M token 多少钱?
不超过 128K 的 prompt 每 1M 输入 tokens $0.50、每 1M 输出 tokens $3.00,缓存输入 $0.10。超过 128K 的 prompt 整单按 $1.00/$6.00 计费。
长上下文档位适用于整单吗?
是。一旦 prompt 超过 128K tokens,该请求中的每个输入与输出 token 都按 $1.00/$6.00 计费。一个 130K-token 请求的成本是同样请求在 128K 时的 2.02 倍。
Doubao Seed 2.0 Pro 用批量处理更便宜吗?
是。Flex 处理约为标准输入输出费率的 50%,同时保持 $0.10 的缓存费率;Batch 推理单独定价,也约为一半。在承诺标准费率前都值得先核算。
Seed 2.0 Pro 与 Seed 2.1 Turbo 有什么区别?
输入价同为 $0.50,但 Turbo 输出为 $2.50(Pro 为 $3.00),而且 Turbo 完全没有长上下文档位——对 256K 以内的请求统一费率。超过 128K tokens 后,Turbo 的价格只有 Pro 的一半。
广告位 Google AdSense 占位——网站通过审批并有稳定流量后启用。
