Doubao Seed 2.1 Turbo 的费用

每 1M 输入 tokens $0.50、每 1M 输出 tokens $2.50,从 1 token 到 256K 全程统一。这个“平”结构就是全部要点:Seed 2.0 Pro 输入同样收 $0.50,但 prompt 一旦超过 128K 就翻倍到 $1.00,所以 Turbo 是整个家族里唯一让 200K-token 文档与短问题保持相同单 token 价格的模型。

缓存命中按 $0.10 计费——输入费率的五分之一——而且 BytePlus 还加收 $0.0083/1M tokens/小时的缓存存储费,这是多数对比都会漏掉的数字。一个在缓存里放了一天的 200K 前缀,光存储就是 $0.04;对热门的 agent 循环微不足道,对只用一次的前缀则是浪费。

Flex 处理约为此费率的一半,只支持隐式缓存;Batch 推理单独定价。在承诺标准费率之前,两者都值得先核算。

国际目录落后于中文目录

火山引擎(中国平台)已经上线 doubao-seed-2.1-pro,标价人民币 12 进 / 60 出,约为 Turbo 的两倍,还有一个在国际上没有对应版本的 doubao-seed-evolving 模型。ModelArk 提供 Turbo 与 Seed 2.0 家族,但不提供 2.1 Pro。

如果你规划的是一个只在中文渠道见过的模型,这个差距就很重要。在围绕它设计方案之前,先确认该模型 ID 在你实际要调用的平台上存在。

常见问题

Doubao Seed 2.1 Turbo 每 1M token 多少钱?
在 BytePlus ModelArk 上每 1M 输入 tokens $0.50、每 1M 输出 tokens $2.50,缓存输入 $0.10/1M。费率在整个 256K 上下文窗口内保持一致。
Doubao Seed 2.1 Turbo 有长上下文附加费吗?
没有。与 128K tokens 以上费率翻倍的 Seed 2.0 家族不同,Turbo 在 250K tokens 时与 250 tokens 时都按同样的 $0.50/$2.50 计费。
BytePlus 对缓存存储收费吗?
收。缓存 token 在 $0.10 缓存命中费率之外,另按 $0.0083/1M tokens/小时收取存储费,因此长寿前缀会带来纯 token 对比容易忽略的持有成本。
我能在国际范围使用 Doubao Seed 2.1 Pro 吗?
截至 2026-10-28,ModelArk 上还没有。火山引擎将 doubao-seed-2.1-pro 标价为人民币 12/60 每 1M,但国际目录只到 Turbo 与 Seed 2.0 家族。
