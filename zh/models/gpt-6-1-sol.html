如何看待 GPT-6.1 Sol 的价格

输出 token 的计费倍率是输入的 5.0 倍,这个数字决定一项工作负载是否负担得起:摘要与分类是输入密集型,而 agent、思维链推理和长篇写作是输出密集型。在比较宣传价格之前,先从自己的日志中测量真实的 token 比例,再用混合公式 (输入占比 × 输入价格) + (输出占比 × 输出价格) 计算。

除了头条费率,通常还有三个杠杆决定真实账单:厂商提供的批量折扣、稳定 prompt 前缀的缓存命中,以及合理选型——把简单步骤交给 mini 或 flash 类模型而不是旗舰。并非所有厂商都同时提供这三项,先逐项确认哪些适用,而不是想当然。 缓存命中按 $0.10 计费,未命中则按 $2,因此被复用的前缀是你买过的最便宜的 token。

常见问题

GPT-6.1 Sol 每 1M token 多少钱?
每 1M 输入 tokens $2.00,每 1M 输出 tokens $10.00。缓存输入按 $0.10/1M 计费,缓存写入在 30 分钟保留期下为 $2.50/1M。
GPT-6.1 Sol 对长 prompt 会加收费用吗?
会。超过 272K 输入 tokens 的请求按输入与缓存费率的 2 倍、输出费率的 1.5 倍计费,即输入 $4.00、输出 $15.00,且适用于整单请求,而非仅超出部分。
GPT-6.1 Sol 有批量折扣吗?
有。Batch 与 Flex 处理为标准费率的 50%($1.00/$5.00),Fast 模式则翻倍至 $4.00/$20.00。
GPT-6.1 Sol 与 GPT-6.1 Terra 有什么区别?
Terra 在输入输出两侧都恰好是 Sol 的一半($1.00/$5.00 对 $2.00/$10.00),上下文窗口同为 1.05M。Sol 面向复杂编程与长周期 agent 工作;Terra 面向高吞吐的计算机使用、视觉推理与写作。
