2026 年 10 月 DeepSeek V4 Pro 的实际花费

$0.66/1M tokens 是非高峰费率,不是牌价。DeepSeek 公布高峰费率,并在两个工作日窗口之外减半:UTC 01:00-04:00 与 06:00-10:00。也就是每天七小时、每周五天,约占日历的 21%。其余 79% 按上述费率计费,中国法定节假日全天按非高峰计算。

缓存命中是这里最宽的杠杆。缓存命中 $0.022/1M tokens,而未命中是 $0.66,相差 30 倍。反复发送同一段长系统提示的 agent 只为它付一次全价,此后几乎不再花钱——这正是下方实际示例从每月 $25.74 降到 $8.51 的原因。

该模型没有批量 API 折扣。DeepSeek 没有公布,因此 OpenAI、Anthropic 与 Google 提供的 50% 异步优惠在这里没有对应项。取而代之的是分时定价;只要你的任务能等一个非高峰窗口,它同样价值 50%。

V4 Pro 还是 V4.1 Flash:价差买到了什么

V4 Pro 输入比 V4.1 Flash 贵 4.4 倍、输出贵 3.3 倍。两个非价格差异决定取舍:V4 Pro 仅文本而 Flash 支持图像;V4 Pro 并发上限 500,而 Flash 是 2,500——当你扇出数百个并行请求时这一点很关键。

按任务形态路由,而不是按型号等级。抽取、分类、图像输入与短对话归 Flash;错误答案代价高昂的长周期推理才用 Pro。把每个请求都以 4.4 倍输入价发给 Pro,很少是正确的默认。

隐藏成本:Search 与 Fetch 从 2026 年 11 月 1 日开始计费

DeepSeek 的 Search 与 Fetch API 按请求计费,每 1,000 次成功调用 $0.75,且在北京时间 2026 年 11 月 1 日 00:00 之前免费。自该日起,检索成为独立条目,因此重度搜索的 agent 要付两次:一次 tokens,一次检索。

实际示例:每轮五次搜索调用、每天 20 轮,就是每月 3,000 次调用,即 $2.25。这约等于在上述 $8.51 token 账单之上再增加 26%。对检索密集的工作负载,搜索这一行可能超过推理本身,而且任何 token 计算器都不会显示它。

常见问题

DeepSeek V4 Pro 每 1M token 多少钱?
非高峰费率下每 1M 输入 tokens $0.66、每 1M 输出 tokens $1.98。工作日高峰(UTC 01:00-04:00 与 06:00-10:00)两项翻倍,分别变为 $1.32 与 $3.96。缓存输入按 $0.022/1M 计费。
DeepSeek V4 Pro 晚上更便宜吗?
是。非高峰费率为高峰费率的一半。高峰每日覆盖七个小时、仅限工作日,因此一周约 79% 的时间按较低费率计费;周末与中国法定节假日全天为非高峰。
DeepSeek V4 Pro 有批量 API 折扣吗?
没有。DeepSeek 未公布该模型的批量折扣,因此 OpenAI、Anthropic 与 Google 提供的 50% 异步优惠在这里没有对应项。可用的是非高峰定价与缓存命中。
该用 V4 Pro 还是 V4.1 Flash?
抽取、分类、图像输入与高并发扇出用 Flash:输入便宜 4.4 倍、输出便宜 3.3 倍,支持图像,且并发上限 2,500 对 500。当推理深度值得这份溢价时,再选择 V4 Pro。
DeepSeek 对 Search 与 Fetch 如何收费?
每 1,000 次成功请求 $0.75,北京时间 2026 年 11 月 1 日 00:00 前免费。此后,检索与 tokens 分开计费,可能使重度搜索的 agent 账单增加约 26%。
广告位 Google AdSense 占位——网站通过审批并有稳定流量后启用。
