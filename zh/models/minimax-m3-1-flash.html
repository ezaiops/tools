MiniMax M3.1 Flash 的费用

每 1M 输入 tokens $0.15、每 1M 输出 tokens $0.60、缓存输入 $0.015/1M——在 1M-token 窗口内为统一费率,没有公布的长上下文倍率。对比 MiniMax M3 的 $0.30/$1.20,是两侧半价,缓存读取便宜 75%。

从数字看,这是本表中最便宜的可信 agent 档位:$0.60 的输出价只在纸面上压过 DeepSeek V4.1 Flash 的 $0.60,因为 DeepSeek 公布的是非高峰价,工作日的七个小时会翻倍。M3.1 Flash 没有分时定价,所以上面的价格就是你在某个周二上午十点要付的价格。

你付出的取舍

总参数 428B、激活参数仅 23B,这是一个为吞吐而非深度打造的稀疏模型——MiniMax 声称约 200 tokens/秒,以及完成 agent 任务的成本下降 70%。这是关于重试次数与回合数的声明,而不是关于单 token 价格的声明。一个用更少步骤完成的模型,比它的价格表看起来更便宜;需要更多步骤的则更贵。

把厂商基准的胜场当作方向性参考,把独立排行榜的位置当作有用的信号。对抽取、分类、工具路由与高吞吐扇出,这个档位如今在价格上很难反驳;对长周期推理,$2-$10 档位依然物有所值。

常见问题

MiniMax M3.1 Flash 每 1M token 多少钱?
每 1M 输入 tokens $0.15、每 1M 输出 tokens $0.60,缓存输入 $0.015/1M。MiniMax 的价格表在 1M-token 上下文窗口内只列出一个价格。
MiniMax M3.1 Flash 比 MiniMax M3 便宜吗?
是。输入输出都是 M3 的 $0.30/$1.20 的一半,缓存读取费率从 $0.06 降至 $0.015/1M。M3.1 Flash 还取消了 M3 对超过 512K tokens 的 prompt 的更高档位。
MiniMax M3.1 Flash 有时段定价吗?
没有。与 DeepSeek 不同,MiniMax 全天统一费率,因此没有可安排批量工作的非高峰窗口,也无需为高峰倍率做预算。
MiniMax M3.1 Flash 是开放权重吗?
是。权重于 2026 年 10 月 23 日以开放许可发布,仅比 API 上线晚四天;总参数 428B,激活参数 23B。
