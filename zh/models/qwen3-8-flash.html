Qwen3.8 Flash 的费用

新加坡每 1M 输入 tokens $0.113、每 1M 输出 tokens $0.382,隐式缓存命中 $0.014。中国香港与美区为 $0.15/$0.47——同一模型贵 33%,与 Qwen3.8 Max 的区域模式一致。

在 $0.382 的输出价下,这是从主流厂商买到 1M-token 上下文窗口最便宜的方式。GPT-6 Luna 单 token 略便宜($0.10/$0.50),但输出成本上限更高;Gemini 3.5 Flash-Lite 输出 $2.50,贵六倍。

便宜费率在哪儿不再便宜

Flash 为吞吐定价,不是为推理深度定价。1M 窗口与原生视频输入让它适合抽取、截图分拣与长文档摘要——这正是输出保持简短、$0.382 费率发挥主要作用的负载。

它不是长周期 agent 工作对 Max 的替代品。如果一个任务需要几十次带重试的工具调用,更便宜模型的更高步数会抹平它的单 token 优势——这也就是为什么该比较每任务成本,而不是单 token 价格。

常见问题

Qwen3.8 Flash 每 1M token 多少钱?
新加坡区域每 1M 输入 tokens $0.113、每 1M 输出 tokens $0.382,隐式缓存命中 $0.014/1M。中国香港与美区(弗吉尼亚)为 $0.15/$0.47。
Qwen3.8 Flash 与 Max 同样有 1M 上下文吗?
有。两者都提供 1,000,000-token 上下文窗口、991,808-token 最大输入与 131,072-token 输出。Flash 以 Max 十分之一的输入价达到该窗口。
Qwen3.8 Flash 是多模态模型吗?
是。支持文本、图像与视频输入并返回文本,且同时兼容 OpenAI 与 Anthropic 两种 API 协议,可直接嵌入 Claude Code 或 Codex 风格的工具链。
