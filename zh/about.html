关于 ezaiops 工具站

免费的 LLM 成本测算与日常工程工具。没有账号，没有上传，也没有任何后端可以存下你输入的内容。

这是什么

tools.ezaiops.com 包含 18 个浏览器端工具，以及覆盖 43 个 LLM 模型的价格数据库。整站是托管在 GitHub Pages 上的静态 HTML、CSS 与 JavaScript——背后没有应用服务器，所以这些工具才敢承诺输入不出本机：根本没有地方可去。

为什么全部在本地运行

大多数免费在线工具的做法是：把你的输入发到服务器、在那边处理、再把结果送回来。选个颜色无所谓，但一段含客户数据的 prompt、一个 JWT、一份合同 PDF 或一把私钥就不行了。这里的工具全部在你已打开的这个标签页里完成解析、哈希、压缩和渲染。其中三个（分词计数、二维码生成、PDF 工具）会在首次使用时从 CDN 下载一个库；库在本地运行，你的内容从不包含在那个请求里。

价格数据怎么维护

站上每一个价格都来自同一个数据文件，每个价格页都会标注最后核对日期。费率直接读各家官方文档——OpenAI、Anthropic、Google、DeepSeek、xAI、Z.AI、Moonshot、MiniMax、小米和 Mistral——而不是抄聚合博客，因为聚合站总是慢半拍。长上下文档位、缓存命中价、Batch 折扣和峰谷时段都按规则显式建模，不会糊成一个平均值。

价格一直在变。如果你发现某个数字和厂商页面已经对不上，告诉我们，我们会改——这是读者能发来的最有价值的一条消息。

我们不做什么

  • 不做账号，不收邮箱，不用订阅墙拦人。
  • 不卖位置：没有人能花钱买对比表里的排序或「最便宜」标签。
  • 不卖也不共享数据，因为工具根本不收集。

谁在做这件事

ezaiops 在 ezaiops.com 写 AI Agent 可观测性、LLMOps 与生产级 AI 运维的实战笔记。这些工具是那些工作的副产品——成本计算器之所以存在，是因为照着价格页估算 agent 的月账单实在烦人；子网和 cron 工具则是因为我们自己一直在用。源码和 issue 都在 GitHub 上。
