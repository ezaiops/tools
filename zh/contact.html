联系我们

价格写错、工具坏了、缺功能——都欢迎反馈。GitHub 是最快的渠道，也能让下一个有同样疑问的人直接看到答案。

怎么找到我们

在 github.com/ezaiops/tools 提 issue。这是唯一的支持渠道：没有支持邮箱、没有工单系统、没有在线客服，因为本站没有后端来跑这些。每一条都会看。

报告价格错误

这是你能发来的最有价值的一条消息，会优先修。想让它变成一分钟就能改完的事，请附上：

  • 模型名称，以及你看的是哪个页面。
  • 你认为正确的数字，以及厂商定价页的链接。
  • 你核对的日期——费率一直在变，上周核对过的页面可能已经过期了。

如果错的是某个计价规则本身——长上下文阈值、缓存命中价、峰谷时段——请说明是哪一档、正确规则是什么。这类问题不会给出「稍微过时」的数字，而是直接算错总额。

报告 bug

请附上页面 URL、浏览器与版本、你的操作步骤，以及实际结果与预期结果的差异。如果怀疑算错了，把输入和你得到的数字贴上来——大部分问题靠这个就能一分钟复现。

提工具需求

说你想要完成的任务，而不是你想象中的那个工具——经常会有更简单的形态。只要能在浏览器里跑完、不需要注册，就是候选。需要服务器、账号或 API key 的，不做。

广告与合作

展示广告通过 Google AdSense 投放，没有可谈的空间。对比表里的赞助位不卖——一个能花钱买排序的价格表，对读它的人来说一文不值。

隐私相关问题

同样通过 GitHub issue 提问。隐私政策说明了本站收集什么、不收集什么；一句话：工具在你自己的设备上处理输入，背后没有账号也没有数据库。

响应时间

尽力而为，没有服务承诺。价格纠错通常几天内改完；工具需求会按「有多少人用得上」来排优先级。如果真的坏了，请在标题里写清楚，会往前排。
