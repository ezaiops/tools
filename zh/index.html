AI 与 LLM

LLM 分词与成本计算器跨 43 个模型统计 token 并估算成本——单次、每日、每月，含缓存与 Batch 折扣。 自托管 vs API 盈亏平衡算出每月用量达到多少时，租 GPU 比按 token 付 API 更划算。

文本与数据

JSON 格式化与校验格式化、压缩与校验 JSON，并精确定位第一个错误的行列。 正则测试器对文本实时测试 JavaScript 正则，查看捕获分组与替换预览。 Base64 / URL / 哈希Base64、URL 编码、HTML 实体与 SHA 哈希，全部本地计算。 Meta 标签与 OG 生成器生成 title、description、Open Graph 与 Twitter 标签，附社交预览。 文本差异对比两段文本的行级与词级差异对比，支持并排与行内两种视图。

时间与调度

Cron 表达式解释器把任意 cron 表达式翻译成人话，并按你的时区列出接下来的运行时间。 Unix 时间戳转换器Unix 时间戳、ISO 8601 与本地时间互转，附带实时时钟。 Cron 可视化排程器可视化选择日期与时间，直接生成 cron 表达式——解释器的反向工具。

网络与安全

密码与 UUID 生成器生成强密码、可记忆短语与 v4 UUID，并给出熵值评估。 子网与 CIDR 计算器任意 IPv4 CIDR 块的网络地址、广播地址与可用主机范围，附二进制分解。 JWT 调试器本地解码 JWT 头、载荷与过期时间，并校验 HS256 签名。

文件与媒体

图片压缩与格式转换在浏览器内压缩 JPG/PNG 并转换为 WebP——不上传任何文件。 PDF 合并与拆分用 pdf-lib 在本地合并、拆分与重排 PDF 页面。 二维码生成器生成 SVG 或 PNG 二维码，支持四档纠错等级。

常见问题

这些工具会把我的数据发送到别处吗？
不会。本站所有工具都在你的浏览器中本地运行。你粘贴的任何内容都不会被上传、记录或存储。
LLM 分词数量准确吗？
对于 OpenAI GPT 系列模型，计数器使用官方 cl100k/o200k 字节对编码分词器。其他厂商的分词方式不同且并非全部公开，因此数量是接近的近似值——请当作估算看待，账单以各厂商用量控制台为准。
模型价格数据来自哪里？
价格收集自各厂商官方定价文档（OpenAI、Anthropic、Google、DeepSeek、xAI、Z.AI、Moonshot、MiniMax、小米、Mistral），并与聚合站交叉核对。每个价格页都标注了最近核实日期。厂商调价频繁，重大决策前请以官方页面为准。
这些工具可以用于商业项目吗？
可以。没有授权费用，也不要求署名。生成结果归你所有。
