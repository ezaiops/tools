Base64 / URL 编码与哈希生成器

Base64 与 URL 编解码、HTML 实体转义，或计算加密校验值——其中的 SHA-256 为纯 JavaScript 实现，在非安全上下文也能用。全程 UTF-8 安全。

SHA-256 使用内置实现；其他算法需要安全上下文（https 或 localhost）
广告位 Google AdSense 占位——网站通过审批并有稳定流量后启用。

编码说明

  • Base64 用 64 个字符的字母表把二进制或 UTF-8 文本编码为 ASCII。这里的编码是 UTF-8 安全的，CJK 文本和 emoji 都能正确往返。
  • URL 编码把 URL 中不允许的字符百分号转义。「组件」模式（encodeURIComponent）转义更彻底——用于查询参数值，不要用于整个 URL。
  • HTML 实体用于防注入：& 表示 &，< 表示 <，以此类推。
  • SHA-256 由内置的 JavaScript 实现计算，任何环境都能用。SHA-1/384/512 使用浏览器原生的 crypto.subtle，需要安全上下文（https:// 或 localhost）——另外 SHA-1 在密码学上已被破解，仅建议用于兼容旧校验和。

常见问题

为什么 Base64 编码会让文件变大？
Base64 把 3 字节编码为 4 个字符，所以输出大约大 33%。这是让二进制数据能穿过纯文本通道（JSON、URL、邮件）的代价。
我的输入会被上传吗？
不会。所有转换都在本地运行，没有任何传输。
令牌用 Base64 还是 hex？
哈希更常用 hex（大多数校验和工具的输出格式）；Base64 更紧凑。本页哈希默认输出 hex，可切换为 Base64。
