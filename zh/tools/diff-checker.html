差异是怎么算的

Line differences come from the Myers O(ND) algorithm — the same family that powers git diff. It finds the shortest edit script (insertions and deletions) between the two line sequences. Modified lines are then paired up and a word-level Myers pass highlights the changed words inside them, which is what makes small edits readable at a glance.

一切都在你设备的 JavaScript 中运行。实际表现接近线性，最坏情况是平方级——粘贴几千行没问题，粘贴整个代码库就不行了。

常见问题

这和 git diff 有什么区别？
行级算法相同，但 git 还会应用启发式规则（差异块头、函数上下文、空白处理）。比较两个任意文本块——邮件、配置文件、草稿——这个工具更快。
会忽略空白吗？
不会——行尾空格也算差异。想要忽略空白的比较，先自行去除两侧空白。
文本会被上传吗？
不会。差异在你的浏览器中计算，页面从不传输内容。
