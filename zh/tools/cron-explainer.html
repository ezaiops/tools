Cron 语法参考

    

      
字段取值范围特殊字符

      
        
分钟0-59* , - /

        
小时0-23* , - /

        
日1-31* , - /

        
月1-12 或 JAN-DEC* , - /

        
周0-7（0 和 7 均为周日）或 SUN-SAT* , - /

      
    

    
特殊字符串：@reboot 启动时运行一次；@yearly/@annually = 0 0 1 1 *；@monthly = 0 0 1 * *；@weekly = 0 0 * * 0；@daily/@midnight = 0 0 * * *；@hourly = 0 * * * *。

    
当月和周两个字段都被限制时，它们之间是「或」的关系——0 0 1 * 1 会在每月 1 日以及每个周一触发。两者都为 * 时才表示「每天」。


    
常见问题

    

      未来运行时间显示的是哪个时区？
      
你的浏览器本地时区。服务器上的 cron 通常以 UTC（或系统时区）运行，所以 UTC 机器上的 0 9 * * * 对 UTC+9 的用户是本地零点触发——信任排程之前，先确认服务器的时区。

    

    

      支持 Quartz 的 6/7 字段表达式吗？
      
不支持——本解释器面向标准五字段 Unix cron。Quartz 表达式额外带有秒和年字段（例如 0 0 9 * * ? 2026），还使用 ?，普通 cron 不认识它。

    

    

      我的 crontab 没有执行，该检查什么？
      
三个常见嫌疑人：cron 守护进程没运行或用户的 crontab 没安装（crontab -l 看不到就是没装）、命令里的路径不是绝对路径、时区和预期不一致。另外 crontab 命令中的百分号必须转义为 \%。
