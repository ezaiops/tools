About ezaiops tools

Free utilities for LLM cost math and everyday engineering work. No accounts, no uploads, no backend that could store what you type.

What this site is

tools.ezaiops.com is a collection of 18 browser-based tools and a pricing database covering 34 LLM models. Everything is static HTML, CSS and JavaScript served from GitHub Pages — there is no application server behind it, which is why the tools can promise that your input stays on your device: there is nowhere for it to go.

Why the tools run locally

Most free online utilities work by posting your input to a server, processing it there, and sending back the result. That is fine for a colour picker and not fine for a prompt containing customer data, a JWT, a contract PDF or a private key. These tools parse, hash, compress and render in the tab you already have open. Three of them (the token counter, QR generator and PDF tools) download a library from a CDN the first time you use them; the library runs locally and your content is never part of that request.

How the pricing data is maintained

Every price on the site comes from a single data file, and each pricing page shows the date it was last verified. Rates are read from the providers' own documentation — OpenAI, Anthropic, Google, DeepSeek, xAI, Z.AI, Moonshot, MiniMax, Xiaomi and Mistral — rather than from aggregator blogs, because aggregators lag. Long-context tiers, cached-input rates, batch discounts and peak/off-peak windows are modelled explicitly rather than averaged into one number.

Pricing changes constantly. If you spot a figure that no longer matches the provider's page, tell us and it gets corrected — that is the single most useful thing a reader can send.

What we do not do

  • No accounts, no email capture, no newsletter gate.
  • No paid placement: nobody can buy a position in a comparison table or a "cheapest" label.
  • No selling or sharing of data, because the tools never collect it.

Who is behind it

ezaiops publishes field notes on AI agent observability, LLMOps and production AI operations at ezaiops.com. The tools grew out of that work — the cost calculator exists because estimating an agent's monthly bill from a pricing page is genuinely annoying, and the subnet and cron utilities exist because we kept needing them. Source code and issue tracker live on GitHub.

Get in touch

Corrections, bug reports and feature requests are all welcome — see the contact page for the fastest route. The privacy policy explains what little data the site touches.
