What runs locally

The whole operation uses pdf-lib, a pure-JavaScript PDF library loaded from a CDN on first use. Your files are read with FileReader, assembled or trimmed in memory, and written back with URL.createObjectURL. No server ever sees the bytes — and no size or rate limits, because there is nothing to meter.

  • Merge concatenates full documents in the order you list them. Bookmarks and form fields from the sources are not preserved.
  • Extract copies the selected pages into a new document. Pages stay exactly as they were — text, images and vector content included.
  • Encrypted PDFs need their password removed before they can be processed here.

Frequently asked questions

Is there a file size limit?
Only your device's memory. Files in the tens of megabytes are fine on desktop; phone browsers start struggling somewhere around 50–100 MB total.
Why is the merged file bigger than the sum of its parts?
It shouldn't be by much — pdf-lib copies pages without recompression, so sizes are roughly additive. If a file balloons, it likely embedded a font that was already duplicated across sources.
Can I rotate, reorder or delete pages?
Not in this version — merge and extract only. Reordering is possible by extracting ranges in the order you want them and merging the results.
