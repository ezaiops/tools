How subnet math works

    
An IPv4 address is 32 bits, written as four octets. The prefix length — the number after the slash — says how many leading bits belong to the network. The network address keeps those bits and zeroes the rest; the broadcast address sets all host bits to 1. Hosts between them (minus the two reserved ends) are assignable, so a /24 gives 254 usable addresses, a /30 gives 2 — the classic point-to-point link.

    
Two details trip people up: usable hosts is 2^(32-prefix) − 2, except for /31 (RFC 3021, both addresses usable on point-to-point links) and /32 (a single host). And a host address like 192.168.1.37/26 is inside the network 192.168.1.0/26 — the calculator always shows the network the address belongs to.


    
CIDR notation, netmask and wildcard mask

    
Three ways of writing the same boundary. CIDR notation counts the network bits: /26. The dotted netmask writes those bits as an address: 255.255.255.192. The wildcard mask inverts every bit: 0.0.0.63. Converting between them is pure arithmetic — count the leading ones for the prefix, invert for the wildcard — which is why the calculator above shows all three at once instead of asking you to pick a format.

    
The wildcard is the one that causes real trouble. Cisco-style ACLs and OSPF network statements expect a wildcard, not a netmask, so pasting 255.255.255.0 where 0.0.0.255 belongs silently matches the wrong traffic. If a rule behaves in reverse of what you meant, check for that swap first.


    
Planning subnets in AWS VPC and other clouds

    
A VPC is defined by one IPv4 CIDR block, and every subnet inside it must be carved from that block. AWS accepts blocks between /16 and /28, so the practical question is always "how many subnets of what size fit in my VPC" — which is exactly what the splitter above answers. A /16 VPC has room for 256 /24 subnets; a common layout uses one /24 per availability zone per tier.

    
The failure that costs the most time is an overlapping block: two VPCs, or a VPC and an on-premises range, or a VPC and a VPN pool that share addresses. Peering and Transit Gateway both refuse to route between overlapping ranges, and the error surfaces far from the cause. Paste your planned blocks into the overlap checker before you create anything — it takes ten seconds and saves a rebuild.


    
Splitting a network, and what VLSM actually means

    
Equal splitting is the easy case: add one bit to the prefix and you double the subnet count, halve the host count. /24 → two /25 → four /26, and so on. The calculator above does that for any block up to 64 subnets.

    
VLSM (variable-length subnet masking) is the case where subnets are not equal — a /26 for the servers, a /28 for the load balancers, a /30 for each point-to-point link. The rule that makes it work is simple: allocate the largest segment first, at the lowest aligned address, then continue with what remains. Do it in the other order and you fragment the space and waste addresses. If you only need equal splits, the splitter is enough; if you are designing a real address plan, size each tier's host count, round up to the next power of two, and work downward.


    
Why this calculator is IPv4 only

    
IPv6 uses 128-bit addresses and has no broadcast address, so the arithmetic here — network, broadcast, usable range, 2^(32−prefix) − 2 — does not carry over. A /64 is the standard IPv6 subnet and holds 2^64 addresses, which makes "usable hosts" a meaningless number to compute. If you need IPv6 prefix math, treat the prefix as a plain bit boundary and skip the broadcast step entirely.


    
Frequently asked questions

    

      How many usable hosts does a /24 have?
      
254. A /24 holds 256 addresses; the network address and the broadcast address are reserved, so 256 − 2 = 254 are assignable. A /25 gives 126, a /26 gives 62, a /27 gives 30, a /28 gives 14, a /29 gives 6 and a /30 gives 2.

    

    

      How do I convert an IP range to CIDR?
      
Enter the first and last address in the IP range to CIDR tool above. It returns the smallest set of blocks that covers exactly that range — for example 192.168.1.10–192.168.1.100 becomes a handful of /31, /30 and /29 blocks rather than one oversized /24. Anything the tool cannot express as a single block is split into the fewest blocks that fit.

    

    

      How do I check if two subnets overlap?
      
Two blocks overlap when one starts inside the other's range: A.network ≤ B.broadcast and B.network ≤ A.broadcast. The overlap checker runs that comparison on every pair, including containment — a /25 inside a /24 counts as an overlap, because both cannot be routed independently.

    

    

      Why do /31 and /32 not subtract two hosts?
      
They are special cases: /31 is defined by RFC 3021 for point-to-point links where both addresses are usable, and /32 is a single-host route (a loopback or a host firewall entry). Everything in between follows 2^(32−prefix) − 2.

    

    

      What is the smallest subnet I can use?
      
On a normal broadcast network, /30 — two usable addresses. /31 is usable on point-to-point links under RFC 3021, and /32 identifies a single host. AWS VPC subnets stop at /28 (16 addresses, 11 usable after AWS reserves five).

    

    

      Is my address sent anywhere?
      
No. All math runs in your browser with JavaScript integer operations; nothing is transmitted. The whole page works offline once loaded.
