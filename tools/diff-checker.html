How the diff works

Line differences come from the Myers O(ND) algorithm — the same family that powers git diff. It finds the shortest edit script (insertions and deletions) between the two line sequences. Modified lines are then paired up and a word-level Myers pass highlights the changed words inside them, which is what makes small edits readable at a glance.

Everything runs in JavaScript on your device. For larger inputs the algorithm is linear-ish in practice but quadratic in the worst case — pasting a few thousand lines is fine; pasting a whole codebase is not.

Frequently asked questions

How is this different from git diff?
Same line-diff algorithm, but git also applies heuristics (hunk headers, function context, whitespace rules). For comparing two arbitrary text blobs — emails, config files, drafts — this is faster to reach for.
Does it ignore whitespace?
No — a trailing space is a difference. Trim both sides first if you want whitespace-insensitive comparison.
Is my text uploaded?
No. The diff is computed in your browser; the page never transmits the contents.
