What each tag is for

  • <title> — the blue headline in search results; also the browser tab name. Keep it under ~60 characters.
  • meta description — the gray snippet under the title. It does not directly rank you, but it decides the click-through rate. Aim for 140–160 characters.
  • link rel="canonical" — tells crawlers which URL is the single source of truth when the same content is reachable several ways (utm params, http/https, trailing slash).
  • Open Graph (og:*) — what WhatsApp, Slack, iMessage and Facebook show when someone shares your link. Missing og:image means an ugly, untrusted plain link preview.
  • Twitter/X card — the same idea for X, with summary_large_image producing the big-image card.

Frequently asked questions

Do meta keywords still matter?
No. Google ignored the keywords meta tag as a ranking signal decades ago. Spending characters there is wasted; Bing has said it may treat them as spam signals. Skip them.
Why does Google show a different description than mine?
Google rewrites descriptions on most queries when it thinks a query-specific snippet from the page body matches better. Write a good description anyway — it still wins for branded and navigational queries.
Where does the image need to live?
Anywhere crawlable with an absolute https URL — your own CDN or static host is best, so you control it. 1200×630 is the universal safe size.
