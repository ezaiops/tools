Why these tools exist

Most "free" online utilities upload your content to a server, wrap a simple operation in a paywall, or bury it under ads before you can use it. These tools are the opposite: every calculation runs entirely in your browser, so a JSON payload, a prompt draft or a password never leaves the page. That also makes them fast — there is nothing to wait for but your own CPU.

The focus is the day-to-day work around LLM-powered systems: figuring out what a call will cost before you ship it, debugging the cron schedule that runs an agent, formatting an API response, escaping a string, or generating credentials for a new service. The LLM pricing pages are updated as providers publish new rates.

This site is maintained by ezaiops, where we write about AI agent observability and production LLM operations. If a tool here saves you time, the blog goes deeper into the same problems.

Frequently asked questions

Do these tools send my data anywhere?
No. Every tool on this site runs client-side in your browser. Nothing you paste is uploaded, logged or stored.
Are the LLM token counts exact?
For OpenAI GPT-family models the counter uses the official cl100k/o200k byte-pair-encoding tokenizer. For other providers the count is a close approximation, because each vendor tokenizes differently — treat their numbers as estimates, and always check the provider's usage dashboard for billing truth.
Where do the model prices come from?
Prices are collected from each provider's official pricing documentation (OpenAI, Anthropic, Google, DeepSeek, xAI, Mistral) and cross-checked against aggregators. Every pricing page shows its last-updated date. Providers change rates often, so verify against the official page before making big commitments.
Can I use these tools for commercial projects?
Yes. There is no license fee and no attribution requirement. The generated output is yours.
