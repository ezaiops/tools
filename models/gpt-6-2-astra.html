What GPT-6.2 Astra costs

$8 per 1M input tokens and $40 per 1M output tokens, with cache reads at $0.40. That is a 20% cut from GPT-6 Astra's $10/$50 and puts it exactly level with Claude Fable 5.2 on headline price — the first time OpenAI's flagship has matched Anthropic's on list price.

The 272K long-context cliff carries over unchanged: a request over 272K input tokens is re-billed for the whole request at $16/$60. OpenAI's own docs are explicit that this applies to the entire request, not just the excess, so long-document pipelines should be sized against the higher tier from the start.

Where Astra sits against Sol and Fable 5.2

GPT-6.2 pairs Astra with Sol at $2/$10. The five-to-one gap between them is the same ladder GPT-6.1 used, and the routing advice is unchanged: Sol for high-volume coding and agent loops, Astra for the slice where reasoning depth decides the outcome.

Against Fable 5.2 the gap is narrower — same list price, and Astra leads on some agent benchmarks (78.3% on Agents' Last Exam) while trailing on the aggregate index. Buyers comparing the two should decide on their own workload mix, not the headline score, because cache pricing and throughput shape the real bill.

Frequently asked questions

How much does GPT-6.2 Astra cost per 1M tokens?
$8.00 per 1M input tokens and $40.00 per 1M output tokens. Cached input bills at $0.40 per 1M, and cache writes cost $10.00 per 1M for a 30-minute retention window or $20.00 for 12 hours.
Does GPT-6.2 Astra charge more for long prompts?
Yes, the same 272K cliff as GPT-6 Astra. Requests above 272K input tokens bill the entire request at double the input and cache rates and 1.5x the output rate: $16.00 in, $0.80 cached, $60.00 out.
How does GPT-6.2 Astra compare with Claude Fable 5.2?
Both list at $8/$40 per 1M, but Astra's cache read is $0.40 against Fable 5.2's $0.20. On Artificial Analysis' index Astra scores 62 against Fable 5.2's 65, and one head-to-head pegged an Astra task at about $4 — roughly 5% of the equivalent Fable 5.2 task cost.
Is there a batch discount on GPT-6.2 Astra?
Batch and Flex processing run at half-price ($4.00/$20.00), Fast mode doubles the standard rate, and Ultrafast bills at 3x. Eligible background requests are 30-40% below Standard depending on the completion window.
