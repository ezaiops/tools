How to read this table

Two numbers do the work: input price (what you send) and output price (what the model generates). Output is billed at 2–8× the input rate depending on the provider, so the headline input price alone tells you almost nothing about a real bill. Cached input — repeating the same long system prompt or context prefix — usually costs a fraction of the base input rate.
