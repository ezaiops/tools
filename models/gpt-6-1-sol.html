How to think about GPT-6.1 Sol pricing

Output tokens bill at 5.0× the input rate, which is the number that decides whether a workload is affordable: summarization and classification are input-heavy, while agents, chain-of-thought reasoning and long-form drafting are output-heavy. Before comparing headline prices, measure the real token mix from your own logs, then apply the blended formula (input share × input price) + (output share × output price).

Beyond the headline rate, three levers usually decide a real bill: batch discounts where the provider offers one, cache hits on a stable prompt prefix, and right-sizing — routing simple steps to a mini or flash-class model instead of the flagship. Not every provider offers all three, so confirm which apply rather than assuming them. A cache hit bills at $0.10 against $2 for a miss, so a reused prefix is the cheapest tokens you will ever buy.

Frequently asked questions

How much does GPT-6.1 Sol cost per 1M tokens?
$2.00 per 1M input tokens and $10.00 per 1M output tokens. Cached input bills at $0.10 per 1M, and cache writes cost $2.50 per 1M for 30-minute retention.
Does GPT-6.1 Sol charge more for long prompts?
Yes. Requests above 272K input tokens are billed at 2x the input and cache rates and 1.5x the output rate, so $4.00 in and $15.00 out, applied to the whole request rather than only the excess tokens.
Is there a batch discount on GPT-6.1 Sol?
Yes. Batch and Flex processing run at 50% of the standard rate ($1.00/$5.00), while Fast mode doubles it to $4.00/$20.00.
What is the difference between GPT-6.1 Sol and GPT-6.1 Terra?
Terra is exactly half the price of Sol on both input and output ($1.00/$5.00 against $2.00/$10.00) with the same 1.05M context window. Sol targets complex coding and long-horizon agent work; Terra targets high-volume computer use, visual reasoning and writing.
