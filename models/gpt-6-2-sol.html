What GPT-6.2 Sol costs

$2 per 1M input and $10 per 1M output, the same card as GPT-6.1 Sol, with a flat rate across the 1.05M context window — no 272K cliff. That flatness is the practical difference from Astra, and it makes Sol the default choice for any workload that regularly passes deep into long context.

Batch and Flex halve the rate to $1/$5; Fast mode doubles it; background completion windows take 30-40% off the standard price.

Sol vs Astra vs Terra

The 6.2 range is a five-to-one ladder from Terra at $1/$5 through Sol at $2/$10 to Astra at $8/$40. Sol takes the middle slot for exactly the work its name implies: everyday professional tasks, coding, and agent loops with a moderate failure cost.

When a prompt routinely crosses 272K tokens, the comparison shifts: Astra re-bills the whole request at $16/$60 while Sol stays at $2/$10. For long-context pipelines that is often the deciding line in the budget.

Frequently asked questions

How much does GPT-6.2 Sol cost per 1M tokens?
$2.00 per 1M input tokens and $10.00 per 1M output tokens, unchanged from GPT-6.1 Sol. Cached input bills at $0.10 per 1M, and cache writes cost $2.50 per 1M for a 30-minute window or $5.00 for 12 hours.
Does GPT-6.2 Sol have a long-context surcharge?
No. OpenAI lists no 272K tier for Sol, unlike Astra — the $2/$10 rate holds across the whole 1.05M context window. For long-document work this makes Sol structurally cheaper per token than the flagships.
What changed from GPT-6.1 Sol?
Pricing and context are identical. The 6.2 update is behavioural: improvements in agentic workflows, code generation and multi-step tasks, with fewer tokens spent per task, which lowers effective per-task cost.
