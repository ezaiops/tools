Doubao Seed 2.1 Turbo API pricing: cost per 1M tokens

Doubao Seed 2.1 Turbo currently costs $0.50 per 1M input tokens and $2.50 per 1M output tokens through the ByteDance API. One flat rate across the whole 256K window — no long-context tier, unlike the Seed 2.0 family. Cache hits bill at $0.10 and cache storage at $0.0083 per 1M tokens per hour. What Doubao Seed 2.1 Turbo costs

$0.50 per 1M input tokens and $2.50 per 1M output tokens, flat from 1 token to 256K. That flat structure is the whole point: Seed 2.0 Pro charges the same $0.50 on input but doubles it to $1.00 once a prompt passes 128K, so Turbo is the only model in the family where a 200K-token document costs the same per token as a short question.

Cache hits bill at $0.10 — a fifth of the input rate — and BytePlus adds a cache storage fee of $0.0083 per 1M tokens per hour, which is the number most comparisons leave out. A 200K prefix held in cache for a day costs $0.04 in storage alone, trivial for a hot agent loop and wasteful for a prefix you touch once.

Flex processing runs at roughly 50% of these rates with implicit caching only, and Batch inference is priced separately. Both are worth checking before you commit to the standard rate.

The international catalogue lags the Chinese one

Volcengine (the China platform) already lists doubao-seed-2.1-pro at CNY 12 in and CNY 60 out, roughly twice Turbo, and a doubao-seed-evolving model with no international equivalent. ModelArk carries Turbo and the Seed 2.0 family but not 2.1 Pro.

That gap matters if you are planning on a model you have only seen announced in Chinese. Confirm the model ID exists on the platform you will actually call before designing around it.

Frequently asked questions

How much does Doubao Seed 2.1 Turbo cost per 1M tokens?
$0.50 per 1M input tokens and $2.50 per 1M output tokens on BytePlus ModelArk, with cached input at $0.10 per 1M. The rate is flat across the full 256K context window.
Is there a long-context surcharge on Doubao Seed 2.1 Turbo?
No. Unlike the Seed 2.0 family, which doubles its rates above 128K tokens per request, Turbo bills the same $0.50/$2.50 at 250K tokens as at 250.
Does BytePlus charge for cache storage?
Yes. Cached tokens cost $0.0083 per 1M tokens per hour on top of the $0.10 cache-hit rate, so long-lived prefixes carry a holding cost that pure per-token comparisons miss.
Can I use Doubao Seed 2.1 Pro internationally?
Not yet on ModelArk as of 2026-10-28. Volcengine lists doubao-seed-2.1-pro at CNY 12/60 per 1M, but the international catalogue stops at Turbo and the Seed 2.0 family.
