Contact us

Wrong price, broken tool, missing feature — all welcome. GitHub is the fastest route and keeps the answer public for the next person with the same question.

Where to reach us

Open an issue on github.com/ezaiops/tools. It is the only support channel: there is no support inbox, no ticket system and no chat widget, because the site has no backend to run one. Everything is read.

Reporting a wrong price

This is the most valuable message you can send, and it gets fixed first. To make it a one-minute fix, include:

  • The model name and the page you were looking at.
  • The figure you expected, and the provider's pricing page that shows it.
  • The date you checked — rates change, and a page verified last week may already be behind.

If a whole tier is modelled wrongly — a long-context threshold, a cached-input rate, a peak window — say which tier and what the correct rule is. Those are the cases where the calculator quietly gives a wrong total rather than a slightly stale number.

Reporting a bug

Include the page URL, your browser and version, what you did, and what happened instead of what you expected. If a calculation looks wrong, paste the inputs and the number you got — most reports can be reproduced in a minute from that.

Requesting a tool

Describe the job you are trying to get done rather than the tool you have in mind; it often turns out there is a simpler shape for it. If it can run entirely in the browser with no signup, it is a candidate. Things that need a server, an account or an API key are not.

Advertising and partnerships

Display advertising is handled through Google AdSense; there is nothing to negotiate. Sponsored placements inside comparison tables are not sold — a pricing table that can be bought is worth nothing to the people reading it.

Privacy questions

Ask through the same GitHub issue tracker. The privacy policy covers what the site does and does not collect; in short, the tools process your input on your own device and there is no account or database behind them.

Response time

Best effort, no service level. Price corrections usually land within a few days; feature requests are considered against how many people would use them. If something is genuinely broken, say so in the title and it moves up.
